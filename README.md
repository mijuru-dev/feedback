# Mijuru feedback

Ideas, wallpaper requests and questions for all Mijuru products — **mijuru.com**, the **browser extension**, the **Linux app** and the **Android app**.

👉 **[Open Discussions](https://github.com/orgs/mijuru-dev/discussions)**

| I want to… | Where |
|---|---|
| 💡 Suggest a feature or improvement | [Ideas](https://github.com/orgs/mijuru-dev/discussions/categories/ideas) — vote 👍 for ideas you like |
| 🖼️ Ask for missing wallpapers (category, resolution, device) | [Wallpaper requests](https://github.com/orgs/mijuru-dev/discussions/categories/wallpaper-requests) |
| ❓ Ask how something works | [Q&A](https://github.com/orgs/mijuru-dev/discussions/categories/q-a) |
| 🐞 Report a problem | an issue in the product repository: [website](https://github.com/mijuru-dev/website/issues/new/choose) · [browser extension](https://github.com/mijuru-dev/wallpapers-browser-extension/issues/new/choose) · [desktop app](https://github.com/mijuru-dev/wallpapers-desktop-app/issues/new/choose) · [mobile app](https://github.com/mijuru-dev/wallpapers-mobile-app/issues/new/choose) |
| ✉️ Something private | m@mijuru.dev |

Please write in **English** — a machine translation is fine. Documentation: [mijuru-dev.github.io](https://mijuru-dev.github.io).

This repository holds only the discussion forms; there is no source code here.
